# Moonlight Widget 🌙 A minimalist black-and-lavender clock for embedding in Notion. Displays the current time in Japan (Asia/Tokyo). ## Publish with GitHub Pages 1. Upload `index.html` to the repository root. 2. In repository Settings > Pages, choose **Deploy from a branch**, `main`, `/(root)`, then Save. 3. Open the published site link. In Notion, type `/embed` (or `/埋め込み`) and paste that URL. ## Customize using Codex Ask Codex to edit `index.html` in this repository. Review changes and merge the pull request to deploy. **Privacy:** The published page is public. Do not put personal notes, passwords, or private API keys into this repository or HTML file.
